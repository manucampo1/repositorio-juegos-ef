# Repositorio de Juegos de Educación Física

Aplicación web estática con 345 juegos y ejercicios, creador de ejercicios, creador de sesiones, situaciones de aprendizaje, guardado local, PDF y modo polideportivo.

## Subir a GitHub Desktop

1. Descomprime el ZIP.
2. En GitHub Desktop selecciona **File > Add local repository** y elige esta carpeta.
3. Si indica que no es un repositorio, pulsa **Create a repository**.
4. Escribe un resumen del cambio, pulsa **Commit to main** y después **Push origin**.

## Publicar en Vercel

1. Importa el repositorio desde GitHub.
2. En **Framework Preset** selecciona **Other**.
3. Deja **Root Directory** en la raíz del repositorio.
4. No es necesario indicar Build Command ni Output Directory: `vercel.json` configura la publicación.
5. Pulsa **Deploy**.

Los datos creados por el profesor se guardan en el almacenamiento local del navegador y se pueden exportar desde la propia aplicación.
